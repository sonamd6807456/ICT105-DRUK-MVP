# Smart Campus Event Hub Go-to-Market Plan

## Product

**Smart Campus Event Hub — Campus Event Management Platform**

## Target Early Users

The first test audience is undergraduate students, international students, and student clubs at Rangsit University. These users regularly look for campus events, activities, workshops, seminars, and club programs but often miss important announcements because event information is scattered across different platforms. Student Affairs staff and club organizers are secondary users because they can publish and manage campus events.

## Main Value Proposition

Smart Campus Event Hub helps students discover, register for, and manage campus events in one centralized platform while helping event organizers promote events and increase student participation.

## Launch Sequence

1. Publish the Smart Campus Event Hub landing page on GitHub Pages.
2. Test that the **Try Smart Campus Event Hub** button opens the working prototype.
3. Create a unique tagged landing-page link or QR code for each marketing channel.
4. Share the landing page with class LINE groups and the international student community.
5. Promote the platform through QR posters, Instagram, Facebook, and student clubs.
6. Record landing-page visitors, CTA clicks, prototype demo views, registrations, and feedback responses daily.
7. Calculate CTA click rate and conversion rate using the agreed formulas.
8. Compare channel performance and improve the landing page, CTA, or prototype navigation.

## Success Criteria for the First Test

The go-to-market success criteria use the same targets and definitions as `docs/startup-metrics.md`.

| Metric ID | Metric | Formula / Counting Method | Success Target |
|---|---|---|---|
| M-01 | Landing Page Visitors | Count users who open the Smart Campus Event Hub landing page | At least 50 visitors |
| M-02 | CTA Click Rate | `CTA clicks ÷ landing-page visitors × 100` | At least 40% |
| M-03 | Prototype Demo Views | Count users who successfully open the Smart Campus Event Hub prototype | At least 30 demo views |
| M-04 | Event Registrations | Count successful event registrations | At least 15 registrations |
| M-05 | Feedback Responses | Count submitted feedback forms or recorded responses | At least 10 responses |
| M-06 | Conversion Rate | `prototype demo views ÷ landing-page visitors × 100` | At least 25% |

These are targets for the initial outreach experiment, not claims of current Smart Campus Event Hub performance.

## Risks and Mitigation

| Risk | Mitigation |
|---|---|
| Students are unaware of the platform | Promote through multiple communication channels and student organizations. |
| Users cannot find event registration | Make the Register button more visible and simplify navigation. |
| Incorrect or outdated event information | Allow administrators to update event details regularly. |
| Low participation during testing | Increase promotion through social media and student communities. |
| Link traffic cannot be attributed to a channel | Use a different tagged landing-page link or QR code for each channel. |
| Small sample size is treated as proof of demand | Report the sample size and describe findings as early validation only. |

## Review Decision

After the first test, the team will compare the observed results with M-01 to M-06. A metric will be marked successful when it meets or exceeds its stated target. If a metric is below target, the team will:

- Improve the landing-page headline if visitor numbers are low.
- Make the **Try Smart Campus Event Hub** CTA more visible if the CTA click rate is below 40%.
- Simplify the route to the prototype if demo views are below 30.
- Improve the event registration process if registrations are below 15.
- Make the feedback form shorter and easier to access if responses are below 10.
- Improve the landing-page-to-prototype journey if conversion is below 25%.

The team will prioritize the marketing channels that generate the highest number of visitors, prototype demo views, event registrations, and feedback responses.
