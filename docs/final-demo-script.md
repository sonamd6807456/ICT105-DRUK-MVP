# Final Demo Script

## Demo Duration

**Recommended duration:** 5–7 minutes

---

## 1. Opening

Introduce the **Smart Campus Event Hub**, explain the problem of scattered campus event information, identify the target users (first-year and international students, student clubs, and campus administrators), and present the platform's value proposition of helping students discover, register for, and stay informed about campus events through one centralized system.

---

## 2. User Scenario

Imagine a first-year student who wants to participate in campus activities but often misses workshops, competitions, and club events because announcements are spread across emails, posters, social media, and messaging applications. Using the Smart Campus Event Hub, the student can quickly discover events, view complete event information, register online, and monitor their participation from one platform.

---

## 3. Prototype Walkthrough

| Step | Screen / Feature | What to Demonstrate | Requirement ID |
|------|------------------|---------------------|----------------|
| 1 | Homepage | Introduce the Smart Campus Event Hub, explain the problem, target users, and navigate to the Events page. | FR-01 |
| 2 | Organizer/Admin Dashboard | Create and publish a new campus event. | FR-02 |
| 3 | Search & Filter | Search for events using keywords and filter by category. | FR-03 |
| 4 | Event Details | Open an event and display the description, date, time, venue, organizer, and available seats. | FR-04 |
| 5 | Event Registration | Register for a campus event and demonstrate the registration process. | FR-05 |
| 6 | Student Dashboard | Show registered events, reminder information, and participation status. | FR-06, FR-10 |
| 7 | Organizer/Admin Dashboard | Manage participant registrations and update event information. | FR-09 |
| 8 | Dashboard & Analytics | Display event statistics, participation metrics, and system summary. | FR-10 |

---

## 4. Evidence and Validation

Explain that usability testing was conducted with students using the Smart Campus Event Hub prototype. Demonstrate the validation results, user feedback, analytics dashboard, and improvements made based on testing, including enhancements to search and filtering, event registration, navigation, dashboard usability, and event management.

---

## 5. Closing

Summarize how the Smart Campus Event Hub solves the problem of scattered campus event information by providing a centralized platform for discovering, registering for, and managing university events. Highlight the improvements made through customer validation and explain that future work includes integrating a secure backend, real-time notifications, and enhanced organizer management features.
