# Landing Page Content

## Project Title

Smart Campus Event Hub

## Target User

The Smart Campus Event Hub landing page is designed for:

- University students, especially first-year students who need help discovering campus activities.
- International and exchange students who may not be familiar with university communication channels.
- Student club members and organizers who create and manage campus events.
- Campus administrators who promote and manage university activities.

## Headline

Discover and Join Campus Events Easily in One Smart Platform.

## Subheadline

Smart Campus Event Hub helps students find, explore, and participate in university events through a centralized platform. Students can discover upcoming activities, register for events, save favorites, and stay updated with campus opportunities.

## Problem Statement

Students often miss important campus events because event information is scattered across posters, social media platforms, messaging groups, and different university communication channels.

Based on Lab 03 customer discovery findings, students experienced difficulty finding reliable and centralized information about workshops, competitions, club activities, and university events.

Lab 08 validation results showed that students, organizers, and administrators needed a simpler way to discover events, manage registrations, and track participation. User testing with 100 participants achieved a high usability score, with most users successfully completing event browsing, searching, registration, and favorite features.

## Solution Description

Smart Campus Event Hub provides a centralized web-based platform where students can discover campus events, view complete event details, register for activities, save favorite events, and receive organized event information.

The platform also supports organizers and administrators by providing event management features to create, update, and monitor campus activities.

## Key Features

| Feature | Requirement ID | User Value | Prototype Screen/Module |
| --- | --- | --- | --- |
| Browse Campus Events | FR-01 | Students can easily discover upcoming university activities in one place | Homepage / Event Listing Page |
| Search and Filter Events | FR-03 | Students can quickly find events based on category, interest, and event type | Search and Filter Module |
| View Event Details | FR-04 | Students can access event information such as date, location, description, and organizer details | Event Details Page |
| Register for Events | FR-05 | Students can join campus activities through a simple registration process | Event Registration Module |
| Save Favorite Events | FR-06 | Students can bookmark interesting events and track activities they want to join | Favorites Page |
| Student Dashboard and Notifications | FR-08 | Students can view participation information and upcoming activities | Student Dashboard |
| Event Management | FR-09 | Organizers and administrators can create, update, and manage event information | Admin Dashboard |

## Benefits

From the user's perspective, Smart Campus Event Hub provides:

- One centralized location for all campus event information.
- Faster discovery of workshops, competitions, seminars, and student activities.
- Easier event registration without searching multiple platforms.
- Better organization of favorite events and participation history.
- Improved awareness of campus opportunities, especially for new and international students.
- More efficient event management for student clubs and administrators.

## Call-to-Action

Students can:

- Explore Campus Events
- Try the Prototype Demo
- Register for Upcoming Events
- Save Favorite Events
- Join User Testing
- Provide Feedback

## Responsible Data Message

Smart Campus Event Hub only collects necessary information required to improve the event experience, such as basic user information, event registrations, favorites, and feedback responses.

User data is used only for:
- Managing event participation.
- Improving event recommendations.
- Evaluating prototype usability.
- Enhancing future platform features.

The platform avoids collecting unnecessary sensitive information and maintains responsible data handling practices.
